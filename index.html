portscan

A fast, concurrent TCP port scanner with banner grabbing. Zero dependencies, one file, Python 3.

Python 3.8+No dependenciesMIT LicenseJSON output
$ python3 portscan.py example.com -p 1-1024 --banners
[*] Scanning example.com (93.184.216.34) - 1024 ports, 200 threads
[+]    80/tcp open  http  | HTTP/1.0 200 OK
[+]   443/tcp open  https
[*] Done: 2 open port(s) of 1024 scanned.

Fast by default

Thread-pool scanning pushes through hundreds of ports per second with tunable concurrency and timeouts.

Banner grabbing

Identifies services and grabs banners, with HTTP probing on common web ports.

Scriptable

Machine-readable JSON output and meaningful exit codes slot straight into CI and audit pipelines.

$ curl -O https://example.com/portscan.py && python3 portscan.py --help
